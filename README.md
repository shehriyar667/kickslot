# KickSlot

A football web app prototype for Karachi: find and book indoor courts, fill your squad and play tonight.

## Features
- Sign up and log in
- Football-only social feed
- Indoor courts list and Karachi map
- Court booking with cost per player
- AI booking agent (rule-based demo)
- Tournaments that teams can register for
- "Need a player" requests
- Player ratings and positions
- Player chat

## Run it
Open `index.html` in any browser. No install needed.

Demo login: ID `123`, password `123`

## Built with
HTML, CSS and JavaScript (single file, no frameworks). Data is sample data and resets on refresh.
